## What Phoenix is

v3's "auto-formalizer + API" identity was **not abandoned as a
direction**. It was refused as a *current product claim* while the
harness, Core, and audit gates were rebuilt from first principles.

Phoenix is the version bump that records that foundation as shipped:

1. A reviewer (human or AI), via the supported CLI, can turn an English
   economic claim into a kernel-checked Lean statement with an auditable
   12-check bundle (the v1 promise — still true).
2. Models **do draft**. Interpretation (`mistral-medium-3-5`) and
   formalization (`labs-leanstral-1-5`) run live through
   `MistralAdapter`. Formalization is **not** entirely user-authored.
   Live formalize is attempted first; `--from-file` is recovery after
   static reject — load-bearing today because labs-leanstral is not
   statement-faithful (0/3 first-try valid on v2p1; ~1/8 on the v1 set).
3. Assist libraries exist for the next layer: a bounded
   kernel-feedback revision loop (`leanecon.revise_loop`) and a
   proof-skeleton contract (`leanecon.skeleton`). They are **not** CLI
   surface yet. They are the constrained substrate a prover agent can
   sit on.
4. The kernel axiom audit (`#print axioms` / `sorryAx` absent) is the
   only pass gate. Bare compile exit 0 is not a pass (B2 spike: 2/8
   false greens).

## v2 promise (what this tag claims)

On simple claims the **pipeline** drafts interpretation and formal
candidates, the **reviewer** owns meaning and the final proof, and the
**kernel audit** guarantees soundness. The 60–70% "model does the first
stretch" target remains the *measured goal* for v3, not a result this
tag pretends to have earned.

## Explicit non-claims (v2)

- No fully autonomous proving; no unattended `VERIFIED`; no production SLA.
- No agents, retrieval corpus, or game-theory Core.
- No path bypassing the reviewer or the kernel axiom audit.
- No claim that the formalizer is statement-faithful, or that the 60–70%
  draft target has been measured and met.
- No graphs / embeddings / LaTeX ingest — those are v3 substrate, not
  this tag.
- No weakening of the v1 freeze (EI 1.0.0, bundle 1.0.0/12 checks,
  Core P2+G7, CLI).

## v3 direction (CTO, 2026-08-12 — not in this tag)

Constrained auto-formalization of natural language (and later a mix of
typing + LaTeX) into formal representations this system already knows
how to audit (today: EI + mapping report + Lean 4; later: graphs /
embeddings / other IRs the prover agent can consume). Decomposition,
kernel-feedback loops wired into the CLI, and richer IRs build **on**
Phoenix — they do not replace the reviewer or the axiom audit.
