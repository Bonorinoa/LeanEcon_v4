## v3 promise (what this tag claims)

On **simple claims** (consumer / CE / FWT envelope, no new Core, no game
theory):

1. Natural-language input is drafted into the existing audited IRs:
   Economic Interpretation + mapping report + Lean 4 statement.
2. Live `formalize` runs the bounded kernel-feedback revision loop
   (`revise_loop`, budget 3) with **real compile-probe feedback**; the
   last audit-clean draft decides the artifact.
3. `skeleton` is a drafting CLI; unresolved `-- GAP:` never reaches
   `verify`.
4. Quality is **measured** on a frozen held-out split by a committed
   scorer (no live provider in CI). **The 60–70% draft target is NOT
   met — verdict MISSED (25% combined).** This tag is honest about that.
5. The reviewer (human or AI) still owns meaning; the kernel axiom audit
   (`#print axioms` / `sorryAx`) is still the only pass gate; `VERIFIED`
   stays 12-check bundle-gated.
